Conectar con GitHub

Ver vídeos no necesita nada. Para aprobar y lanzar pedidos desde aquí, crea una llave de acceso (solo una vez por dispositivo; se guarda únicamente en este navegador):

  1. Abre esta página de GitHub.
  2. Token name: panel-curiosidario. Expiration: 1 año (o la que quieras).
  3. Repository access: Only select repositories → .
  4. Permissions → Repository permissions: Actions = Read and write, Issues = Read and write.
  5. Pulsa Generate token, cópialo y pégalo aquí.

El panel te avisará arriba 14 días antes de que caduque (GitHub también te manda un correo). Cuando caduque, repite estos pasos y pega la nueva.
