# Voces oficiales del canal

Cada voz es un audio de referencia (`.wav`) y su transcripción exacta (`.txt`). El sistema las clona con
VoxCPM2 (licencia Apache-2.0) para que todos los vídeos usen siempre las mismas voces.

| Voz | Origen | Uso |
|---|---|---|
| `narrador` | Voz de un creador amigo, **con su permiso** para usarla en el canal Curiosidario | Narrador de historias y de comedia |
| `narrador_en` | Diseñada desde cero con VoxCPM2 a partir de una descripción (voz sintética propia, no clonada de nadie) | Narrador del canal en inglés (The Curio Lab) |
| `chico_chulito`, `chico_grave`, `chico_nervioso`, `chica` | Diseñadas desde cero con VoxCPM2 (voces sintéticas propias) | Personajes de los sketches |

Para añadir o cambiar una voz: pon un `.wav` limpio de 10-30 s (sin música) y un `.txt` con lo que dice, con el mismo nombre.
