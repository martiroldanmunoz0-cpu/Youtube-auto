# Política de privacidad – Historias Nocturnas

Última actualización: 18 de noviembre de 2026

**Historias Nocturnas** es una herramienta privada que usa el propietario de este repositorio para gestionar su propio canal de YouTube. No tiene otros usuarios.

## Qué datos usa
- **Datos públicos de YouTube** (títulos y estadísticas de vídeos públicos) obtenidos con la API de YouTube, para analizar tendencias.
- **Acceso al canal del propietario**, únicamente para subir y programar los vídeos que él mismo aprueba.

## Qué no hace
- No recoge datos de otras personas.
- No vende ni comparte datos con terceros.
- No publica nada sin la aprobación del propietario.

## Almacenamiento
Las credenciales se guardan cifradas como secretos de GitHub Actions. Los resultados del análisis se guardan en este repositorio.

## Revocar el acceso
El acceso puede retirarse en cualquier momento desde <https://myaccount.google.com/permissions>.

## Servicios de terceros
Esta herramienta usa los Servicios de API de YouTube. Consulta también los [Términos de servicio de YouTube](https://www.youtube.com/t/terms) y la [Política de privacidad de Google](https://policies.google.com/privacy).
